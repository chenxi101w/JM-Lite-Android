## 二、影响评估

**搜索功能本身完全不受影响**，删除的只是「采样与展示」：

| 保留 | 说明 |
|---|---|
| JSON 接口搜索链路 | 逻辑一行未动，仍优先走接口、失败静默回退 Python |
| 失败回退告警日志 | 仍保留 `Log.w("JmRepository", "JSON 接口搜索无结果，回退 Python 链路")` |
| 搜索页空态 / 结果网格 | 不受影响 |

删除后**不再产生任何搜索行为的本地记录**（此前会以紧凑串形式写入 SharedPreferences `jm_search_perf`）。
已存在的旧记录**保留在设备上不会自动清除**，但 App 不再读取；如需彻底清掉设备上的残留，
可在应用信息里清除数据（会一并清掉书架等，通常无必要）。
