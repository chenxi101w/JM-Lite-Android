# JM 轻量版 v1.0.0 升级日志

**版本号**：versionName 1.0.0 / versionCode 1
**日期**：2026-09-29
**DB**：沿用原工程 v13（无 schema 变更）
**包名**：`com.example.jmreader`（与原版 `com.example.jmcomicreader` 独立，可并存安装）

## 版本说明

轻量版首版：从完整版 jmcomicreader v7.3.1 精简而来，只保留三个核心能力——**书架阅读 + 关键词搜索 + 下载**。按用户要求删去所有非核心功能。

---

## 一、删去的内容

### 书架页（LibraryScreen / LibraryViewModel）
- 顶栏全部按钮：回收站入口、排序菜单、批量删除、分类模式、下载管理入口
- 分类筛选 chips（全部/默认分类/收藏/自定义分类）
- 分类管理弹窗（ModalBottomSheet + CatRow）
- 订阅更新区块（原 v7.2 在发现页，本版无）
- 收藏按钮、批量删除模式（LibMode 精简为无）
- **只保留**：点卡片阅读、卡片删除按钮、看完标记（ComicGrid 按 finishedIds 分区，看完沉底 +「已看完」分隔线）

### 发现页 / 搜索（DiscoverScreen / SearchScreen）
- 推荐流（HomeRecommendBody / HomeViewModel 的 buildRecommendations）
- 订阅作者新作区块
- 搜索态-推荐态切换（inSearch/userSearching 状态机删除，进页即搜索）
- 搜索模式切换（作者/标签）、标签输入+逻辑、排序/时间筛选、搜索历史、长按屏蔽菜单
- **只保留**：关键词搜索框（回车即搜）+ 结果网格（点卡片进详情/下载/加载更多）

### 设置页（SettingsScreen 及所有子页）
- 全部子页：外观 / 阅读 / 下载设置 / 搜索设置 / 标签库 / 标签管理 / 同义词 / 隐藏下载
- 设置主页的分组网格（settingsGroups / SettingsEntry / SettingsBox）
- **设置页改为「关于」页**：图标 + 名称 + 版本号 + 内存占用（安装包/用户数据/漫画本体）+ 下载管理入口

### 后台逻辑
- 订阅检查全部移除：`autoCheckSubscriptionsIfDue` / `scheduleSubscriptionCheck` / `notifySubscriptionsFound` / `SubscriptionCheckWorker` / 通知渠道
- 回收站机制顶部入口删除，`checkRecycleExpiry` 启动扫描删除

### 删除的文件
- settings/：SettingsAppearancePage / SettingsDownloadPage / SettingsReadingPage / SettingsTagsPage / SettingsTagsManagePage / SettingsSynonymsPage / SettingsSearchPage / SettingsHiddenDownloadsPage / SettingsAboutPage / CategoryManagementScreen / SettingsModels / SettingsComponents
- recycle/：RecycleScreen / RecycleViewModel
- worker/：SubscriptionCheckWorker

## 二、行为变化

| 项目 | 完整版 | 轻量版 |
|---|---|---|
| 删除漫画 | 进回收站（可恢复） | **彻底删除**（本地 + 记录，不可恢复，removeBookCompletely） |
| 看完整本 | 宽限期 7 天自动清本地 | **只标 finished**（书架沉底），不清本地 |
| 下载管理入口 | 书架顶栏 + 设置 | 设置（关于）页按钮 |
| JM 号下载 | 下载管理页 | 保留（下载管理页） |
| 底部导航 | 书架 / 发现 / 设置 | 书架 / 搜索 / 关于 |

## 三、保留的内容

- 阅读核心：详情页、阅读器（本地章节、进度续读、读完标记）、章节读完自动删章
- 下载核心：整本下载（jmcomic 2.7.3 + Python 桥）、下载管理页（进度/取消/重新下载/JM号下载）、下载后行为
- 首启自检（v7.3.0）：版本数据修正点 + 数据体检 + 故障识别 + 弹窗报告
- 主题体系（亮/暗/跟随系统 + 动态取色 + 主题风格），入口固定在状态（无设置 UI）
- 离线阅读、封面缓存、Coil 内存/磁盘配置

## 四、验证

真机确认：① 与完整版可并行安装（不同包名）；② 书架只显示已下载漫画，点卡片阅读/删除键彻底删除，看完沉底；③ 搜索关键词出结果、加载更多、点卡片进详情可下载；④ 设置（关于）页显示版本与内存占用、下载管理入口可用；⑤ JM 号下载可用；⑥ 启动无订阅检查/回收站通知干扰。
