# v1.28.0 首页改版：搜索页升为首页 + iOS 风格顶部区 + 分类/排序

> 需求原文见 `docs/需求/20261016_首页改版.md`（**先落盘再实现** —— 这条需求曾在 12:49
> 因会话进程崩溃丢失过一次，用户重新回忆复述）。

## 一、Tab：搜索 → 首页，且提到第一位

| | 改前 | 改后 |
|---|---|---|
| 顺序 | 书架 / 搜索 / 设置 | **首页 / 书架 / 设置** |

## 二、顶部区整体重做（iOS 风格）

### 2.1 搜索栏：去掉「聚焦蓝边」

原实现用 M3 的 `OutlinedTextField` —— 它获得焦点时会画一圈**主题色描边**，
用户原话：「别再搞点搜索就蓝边的那种垃圾动画了」。

改为 `BasicTextField` + 自绘 `decorationBox`：

- **无描边、无 divider、无浮动 label**；聚焦时**只有光标在闪**（真正"无感"）；
- 浅灰填充胶囊（`onSurface` 6% 透明度）+ 全圆角 —— iOS / Telegram 的做法；
- 有内容时右侧出现 **清空按钮**（iOS 习惯）；
- 总高 46dp（胶囊本体 36dp + 上下各 5dp 留白）。

### 2.2 分类栏：**只有一行** = chips + 最右侧「排序」小按钮

用户要求：「咱们搞成一行，…最新、最多喜欢、总排名、月排名、周排名等搞成一个小按钮
放这一行最右边，搞成点一下就向下展开那种」。

```
┌─────────────────────────────────────────────────────────┐
│  [全部] [悬疑] [萝莉] [御姐] …滚动…        [最新 ⌄]     │
└─────────────────────────────────────────────────────────┘
                                          ↓ 点一下向下展开
                              [最新] [最多喜欢] [总排名] [月排名] [周排名]
```

- chip 也换成 iOS 风：**无边框**，未选中 `onSurface` 6% 浅灰，选中 `onSurface` 深色底 + 反白字；
- 「全部」= 不过滤（清空关键词）；
- 排序按钮显示**当前排序** + 上下箭头，点击切换展开；
- 展开动画：面板高度记进 `expandedDp`，外层 Box 高度从 A 动画到 A+PANEL_ROW，
  配合 `clipToBounds` 就是**向下展开**（不用嵌套 AnimatedVisibility，避免双重动画）；
- 面板横向可滚（5 个 chip 在 360dp 窄屏会挤爆）。

### 2.3 分类栏两种模式（新增设置项）

设置 → 搜索 → **分类栏**：

| 值 | 效果 |
|---|---|
| `scroll`（默认） | **随搜索栏一起收拉** —— 与搜索栏同在可收放区，一起隐藏/出现 |
| `stay` | **常驻显示** —— 跟漫画列表一样一直在，不参与收放 |

### 2.4 搜索栏随上下滑动拉起收起

沿用 v1.25.0 的机制（下滑收起、上滑展开、只认方向不跟手），本次适配了新结构：
- 可收放区高度 `expandedDp = 搜索栏 46 +（scroll 模式下）分类行 42 +（面板展开时）44`；
- 收起时**顺手收起排序面板**，否则展开态会一直挂着；
- 仍沿用 v1.27.0 修过的教训：**用 `Column` 顺序排布**（不用 `Box`），
  且**分类行里的 `LazyRow` 必须显式给 height** —— 否则会被量满并吃掉兄弟节点的点击。

## 三、排序接后端（带回落兜底）

原实现里 `BookLibrary.search` 有一道守卫，**只放行 `orderBy=mr`**，其它一律返回空列表
（注释写的是"接口参数枚举未逐一验证"）。本次：

1. `JmApiClient.search(keyword, page, order)` 新增 `order` 参数（非 `mr` 时才带上）；
2. `BookLibrary` 放开白名单 `mr / mv / mp / tr / md / mv_m / mv_w`；
3. ⚠️ **加了回落兜底**：非 `mr` 排序若返回空，用 `mr` 再试一次。
   这样即使接口不认某个枚举，最坏情况也只是「排序没生效」，**绝不会变成"搜不出东西"**。

> **待真机验证**：`md`（总排名）/ `mv_m`（月排名）/ `mv_w`（周排名）这三个取值是推测的，
> 需要真机逐个点一遍。验证方法：搜一次后看日志，若出现
> `order=xx 无结果，回落 mr 重试` → 说明接口不认该值，需要换值。

## 四、已知未做

## 真机待验证

1. 底部第一个 Tab 是**首页**、图标是房子；App 启动就落在首页。
2. 搜索框**点进去没有蓝边/描边**，只有光标闪；有内容时右侧有清空按钮。
3. 分类行**只有一行**，最右侧有「最新 ⌄」小按钮；点一下**向下展开**排序面板。
4. 点排序项 → 面板收起 + 选中项高亮 + 重新搜索（日志看是否有回落提示）。
5. 设置 → 搜索 → **分类栏**切「常驻显示」→ 分类行不再随滑动消失；切回「随搜索栏收放」→ 一起收放。
6. 下滑内容 → 搜索栏 + 分类行一起收起；上滑 → 一起出现。
7. 分类 chip 点击能搜到结果；「全部」清空关键词。
