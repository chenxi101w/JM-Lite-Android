# v1.16.0 — 新主题「暮紫极简」（参考 YOMII 的克制分层哲学）

> 用户指定：参考 jm-comic-android（YOMII）的美术风格做一套我们的主题 UI，**紫色为主**。

## 风格解析（YOMII 的美术精髓）

YOMII 的主题代码只有 3 个文件、全部黑白灰——它的"好看"不在颜色而在**分层克制**：
- 亮色底 `#F9F9F9`（不是纯白）、暗色底 `#0F0F0F`（不是纯黑），微灰打底；
- surface 全家桶（Lowest→Highest）以 1~6% 的亮度差逐级加深，层次全靠灰阶撑；
- 主色低饱和、outline/text 全部灰阶、**零彩色点缀**。

## 我们的设计转译

同样的分层骨架，把"黑白灰"换成"紫灰"：
- 主色 = 沉稳紫 `#5B3FA8`（亮）/ 亮紫 `#C9BCFF`（暗），低饱和不刺眼；
- 亮色底 = 微紫灰白 `#F8F7FB`，暗色底 = 近黑微紫 `#0F0F14`；
- `surfaceContainer` 全家桶（Lowest→Highest = FFFFFF→E9E8F0 亮 / 0C0C10→25252C 暗）逐级加深，还原 YOMII 的分层手感；
- 文字/描边全用紫灰阶（1A1822/5C5868/8B8798），保持"零彩色点缀"的克制。

## 接入

- `Theme.kt`：新增第四风格 `Violet`（light+dark，含 surfaceContainer 全家桶）；
- 设置 → 外观 → 主题风格新增「暮紫」（选项首位）；
- **默认风格 ink → violet**；**动态取色默认关闭**（Android 12+ 动态取色会盖掉主题风格，关闭才能让暮紫默认可见；可在设置重新开启）。
