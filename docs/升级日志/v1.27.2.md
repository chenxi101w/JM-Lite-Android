# v1.27.2 底栏改成「悬浮胶囊」——按录屏实测重做

## 我错在哪（先说结论）

用户说参考实现的底栏「会随滑动收起/出现」，我两次用「源码里没有」当证据否定它：

1. 第一次用 `--depth 1` 浅克隆，只有 1 个提交；
2. 第二次拉了全历史（74 提交 / 37 tag），还是搜不到，我又下结论「不存在」。

**两次的推理链都是坏的**：那份公开源码本身是残的 —— Release 3.8.4～3.8.8 五个版本**全部指向同一个 commit**，Release 说明里的功能（NiceCat 搜索、搜索排序、随机推荐）源码里一个都没有，`ui/search/SearchScreen.kt` 只有 49 行。

**用户的判断是对的，我的"证据"不可靠。** 教训：判断某开源项目"有没有某功能"之前，先验证**源码与发布产物是否一致**，否则结论根本不成立。

（补充：后来也确认无法靠反编译抄 —— APK 被 `dev.mocika.shield` 加固，`classes.dex` 只有 19 个类，真 dex 是加密载荷、启动时内存解密。**绕过加固去拿实现这条我不做**。）

## 改用「录屏量像素」拿到真实参数

用户录了两段屏，576×1280 ↔ 真机 1080×2400（系数 **0.625 px→dp**，density=3）。我用 ffmpeg 抽帧 + PIL 逐像素量：

| 项 | 录屏像素 | 换算 |
|---|---|---|
| 胶囊高 | 89（y 1168..1256） | **56dp** |
| 左/右边距 | 21 | **13dp** |
| 距屏幕底 | 24 | **15dp**（浮在手势条上方） |
| 圆角半径 | 24 | **15dp**（**圆角矩形**，不是全圆角胶囊） |
| 图标 ink | 26×23 / 29×29 | **约 22~24dp** |
| 文字单字宽 | 15~17 | **约 11sp** |
| 图标↔文字间距 | 15 | **约 5dp** |
| 三项中心 x | 112 / 288 / 466 | 等宽各 110dp |
| 红点角标 | 12×10 | **约 7dp**，在「我的」图标右上角 |
| 胶囊上/下边缘 | y≈1167 / 1257 | 居中，圆角约 28dp |

**圆角与边距用「逐像素亮度曲线」定死**（视频 H.264 压缩有噪声，肉眼看图会误判）：胶囊上边缘 y=1168 处亮度 244→255 跳变、下边缘 y=1256 处 255→237，故 89px=56dp；左边缘的圆角轮廓「顶部 dx=24px、往下 24px 收到 0」→ 半径约 15dp，**不是全圆角**。

**收放也量到了**：给「底栏三项在固定 x 的暗像素簇」建立特征，6 秒内反复在「底栏特征 ↔ 漫画封面」之间切换 → 底栏确实随滑动收起/出现。

## 三处结构性修正

### 1. 通栏 → **悬浮胶囊**（最重要）

| | 改前 | 改后 |
|---|---|---|
| 形状 | `fillMaxWidth` 白条贴屏幕底 | **左右各 15dp 边距、圆角 28dp、阴影 10dp** 的胶囊 |
| 位置 | 贴在底部 | **浮在手势条上方**（底边距 15dp） |
| 与内容关系 | 内容被留白推开 | 胶囊**浮在内容之上** |

### 2. 竖排 → **横排**

v1.27.0 我按「字比图标小」的诉求把图标改成在文字**上方**（竖排）。
**方向错了** —— 参考本来就是**图标 + 文字横排**，字只是比图标小一号。
现在：`Row { Icon(22dp); Spacer(5dp); Text(11sp) }`。

### 3. 每个 Tab 一个渐变色 → **单色**

实测参考的选中态是**纯黑图标 + 黑色加粗文字**，未选中是灰色，
**没有渐变、没有背景药丸、没有指示器**。
所以去掉 `TopLevelRoute.gradient`，统一取 `onSurface`（黑）/`onSurfaceVariant`（灰）。

> 想恢复彩色渐变：把 `CompactTabBar` 里两处 tint/color 换成按 Tab 取色即可。

### 保留：收放用「平移」不用「压高度」

v1.27.0 的「高度压 0 → 点击区消失 → 点不了」是硬 bug，v1.27.1 已改成平移，本版沿用：
- 胶囊自身尺寸恒定，收起 = 整体平移出屏幕外；
- 触发用**累积位移**（下滑累计 48px 收、上滑累计 12px 回），不会手一抖就消失；
- 进入页面 / 切 Tab 一律复位成可见。

## 已知差异（未做，等确认）

1. **红点角标**：参考的「我的」图标右上角有个约 7dp 红点。我们没有对应数据（比如未读/未登录），**没加**。
2. **Tab 语义**：参考是 首页/分类/我的；我们是 书架/搜索/设置（按本项目既有功能保留）。
3. **图标**：参考用 Home/Category/Person；我们对应语义用 `Bookmarks`/`Search`/`Settings`。
4. **收放动画时长**：录屏 30fps 下转场被内容滚动掩盖，没能精确量出（估计 ≤200ms），
   现用 220ms。若手感不对再调。

## 真机待验证

1. 底栏是**左右有边距的白色胶囊**，圆角、有阴影，浮在手势条上方。
2. 三项是**图标在左、文字在右**横排；选中项**黑色加粗**，未选中灰色。

5. 切 Tab / 从详情页返回后，胶囊是**可见**状态。
6. 胶囊浮在内容上，滑出后底部内容能正常点、正常滚。
7. 最后一行漫画卡片不会被胶囊永久压住（底部留白 = 56 + 10 + 系统区）。
