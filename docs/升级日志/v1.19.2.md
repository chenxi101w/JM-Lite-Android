## 一、先认错：v1.19.1 理解偏了

用户原话：「**我是让你把图标保留所有细节的同时按照人家的方式搞成 3d 的锃亮的效果**」。
v1.19.1 我拿文生图**重新设计**了一个极简玻璃书图标，把原来那套「粉框 + 翻开的书 + 放射线 +
爱心 + 星星 + 闪电 + 气泡 + 对话泡」的可爱风全丢了 —— 方向错了，**已在 v1.19.2 撤销**（原图标完整恢复）。

## 二、正确做法：图生图，只换材质

- **输入**：原图标（`mipmap-xxxhdpi/ic_launcher.png`，192px，项目里没有更大源图）
  → LANCZOS 放大到 1024 并做 UnsharpMask 锐化，白粉底铺满，作为 img2img 底图；
- **`input_fidelity = high`**（高保真度，尽量贴住原图）；
- **提示词只谈材质、明确禁止改设计**：逐条点名「粉框 / 翻开的书与横线 / 放射线 / 爱心 /
  星星 / 闪电 / 气泡 / 对话泡」都要原位原样，**不许增删或重设计**；只把渲染换成
  亮面搪瓷/塑料 + 厚倒角 + 强高光 + 轮廓光 + 内发光 + 书本下方投影 + 影棚打光。
- 结果：构图与全部元素保留，观感变成 3D 锃亮（对比图见
  `test/icon3d/compare_old_vs_new.png`，左=原图，右=新版）。

## 三、水印处理（这次的手法可复用）

生成图右下角照例带「AI生成 WORKBUDDY」，这次压在**粉色圆角边框**上（不是平滑渐变区，
上一版的「裁掉」法不适用）。试过两条错路：降采样重建留鬼影、**水平镜像左下角
→ 圆弧定位对不上、接缝明显**。
✅ **正解：用「左上角旋转 180°」补右下角** —— 圆角矩形在 180° 旋转下自身重合，
所以左上角的内容转 180° 后与右下角**逐像素对齐**；贴的时候用「内实外虚」蒙版
（核心 100% 替换 + 边缘 24px 渐变，再高斯羽化 16）消除接缝。
→ 一句话：**对称图形的局部修补，先想对称变换，别急着插值。**
