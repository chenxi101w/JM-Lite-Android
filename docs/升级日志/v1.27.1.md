# v1.27.1 修「导航栏搞小的点不了」——底栏收放方式重做

## 用户反馈（原文）

> 人才啊，把导航栏搞小的点不了，没谁了

> 这三个底栏怎么可能没收拉，我明明看到了，主页或者分类向下滑动时自动收起来了，向上滑动又出现了

---

## 一、我犯的错

v1.27.0 里底栏收放是这么做的：

```kotlin
Box(
    modifier = Modifier
        .fillMaxWidth()
        .height(with(density) { (52f * expand).toDp() })   // ← 高度动画
        .clipToBounds()
) { Row(...) { /* 三个 Tab 各自 weight(1f) + fillMaxHeight() + clickable */ } }
```

**把整条栏的高度从 52dp 动画到 0，等于连点击区一起变成 0 高。**
底栏是真·消失，只能靠上滑唤回 —— 用户想切页时点不到，是必然的。

叠加两个放大问题：
1. **触发门槛只有 6px**（单帧 `dy > 6f`）。手指随便一抖就满足，底栏长期处于收起态。
2. **高度压缩过程中图标被 `clipToBounds` 切半**，看起来就是「导航栏被搞小了」。

这是设计缺陷，不是参数没调好。

## 三、新做法：整条滑出屏幕

### 关键改动：不再动高度，改成动位置

| | v1.27.0（错） | v1.27.1 |
|---|---|---|
| 收放方式 | `height(52dp × expand)` → 0 | `offset(y = 栏总高 × 滑出度)` |
| 栏自身尺寸 | 被压到 0 → **点击区消失** | **恒定 52dp** |
| 中间态 | 半高、图标被 `clipToBounds` 切 | 没有中间态，只是移出屏幕 |
| 收起后的状态 | 还在原处，但是 0 高、点不到 | 完全在屏幕外（不可见即不可点，符合直觉） |

### 底栏从 `bottomBar` 槽位改成悬浮覆盖层

原因：`Scaffold` 的 `bottomBar` 槽位**高度一变，content 的 padding 就跟着变** → 内容跳动。
现在底栏是内容层之上的覆盖层，内容用**固定底部留白** `tabBarTotal`（52dp + 系统导航栏安全区）避让：

- 留白恒定 → 底栏滑动时内容**完全不跳**；
- 底栏滑出后，底部露出的就是漫画内容本身（列表在中段滚动时底部本来就有内容，不会出现空白块）；
- 悬浮球的 `safeBottomPx` 也从 `merged` 取，逻辑不变。

### 触发阈值：从「单帧 6px」改成「累积位移」

```kotlin
private var acc = 0f            // 方向切换后累积的位移
acc += consumed.y
if (acc > 48f && dir != 1)  { dir = 1;  acc = 0f; 收起 }   // 下滑累计 48px（≈16dp）
else if (acc < -12f && dir != -1) { dir = -1; acc = 0f; 展开 }  // 上滑累计 12px 就回来
```

- 下滑要累计 **48px** 才收：正常翻页轻松超过，手指微抖不会误触；
- 上滑只要累计 **12px** 就放回来：想切页时往上蹭一下就回来，不别扭。
- 不消费 `available`，列表照常滚 —— 不改任何页面的列表代码（沿用 v1.23.0 的锚点）。
- 悬浮球共用这个连接器，一起收放（顺带也降低了它的误触）。

### 进入即展开

`LaunchedEffect(currentRoute)` 里 `tabHide.snapTo(0f)` —— 切 Tab、从详情页返回都复位成可见。

## 四、如果还是不满意

代码里只动一处就能退回「底栏永久常驻」：

```kotlin
// MainScaffold.kt
val barCollapsible = false      // 改成 false：底栏永不下滑，等同于一直可见
```

（`barCollapsible` 为 `false` 时，`tabHide` 恒为 0，底栏永远停在屏幕底部。）

## 真机待验证

1. **书架页 / 搜索页**：向下滑动漫画列表 → 底栏整条滑出屏幕下方；向上滑动 → 滑回来。
2. **不再出现「被压扁」**：滑动过程中不出现半高、图标被切一半的中间态。
3. **切页后底栏是可见的**（含从详情页返回、点 Tab 切换）。
4. **轻点一下（不滑动）不会让底栏消失**（48px 累积门槛）。
5. **底栏滑出后，底部露出的内容能正常点**（卡片可点、可滚动）。
6. **设置页 / 详情页 / 下载页底栏常驻**（只有书架与搜索页参与收放）。
7. 底栏可见时，三个 Tab 点击区域正常（不再有「点不了」）。
