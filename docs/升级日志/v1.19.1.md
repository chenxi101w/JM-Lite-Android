## 一、先明确一件事：桌面图标不能是动图

Android 的启动图标是**静态资源**（`mipmap` 位图 / 自适应图标的分层矢量），桌面不会去播放动画 —
只有个别厂商桌面自己有动效，不受 App 控制。所以「动」只能落在两处，本轮两处都做了：

1. **App 内展示时动**（关于页顶部那块 3D 极光卡：图标会做 rotationY ±16°/rotationX 4~12° 的
   真透视翻转 + 表面镜面扫光 —— v1.19.0 已就位，本轮换图后自动生效）；
2. **导出一份动图**给用户看/分享（不参与装机）。

## 二、新图标

- 生成：**ImageGen 文生图**（1024²，玻璃/亚克力材质 + 强高光 + 边缘轮廓光，
  深紫→洋红→青 的 squircle 渐变底，中心是一本翻开的玻璃书）。
- **去水印**：生成结果右下角带「AI生成 WORKBUDDY」水印，且它压在平滑渐变区。
  处理过程（记下来免得下次重走弯路）：
  - ❌ 降采样重建 → 文字亮度被平均进渐变，留一层鬼影；
  - ❌ 中值滤波（13/9）→ **字形笔画 30px+，比核大，压不掉**；
  - ❌ 扩散填充 → 掩膜把 squircle 的圆弧边缘也认成「文字」，补出方块接缝；
  - ✅ **最终解法：直接裁掉含水印的那一条**（水印在 y≥948，而图标主体到 y≈830 结束）
    → 裁 `(40,0,984,944)` 得到 944² 正方形 → **均匀放大**到 1024（不拉伸变形）
    → 套自己的圆角遮罩（半径 240 ≈ 23%）。
- 已替换：`mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`（48/72/96/144/192）
  与 `drawable-nodpi/ic_launcher_preview.png`（App 内预览，关于页 3D 卡用的就是它）。
- 旧图标已备份到 `D:/code/CODE/AI-Windows/project/jmcomicreader-lite/test/icon3d/backup_old_icon/`
  （且 git 历史里也有，随时可回退）。
- 其余 5 个图标变体（alt1/alt2/豆包2~4）**未动**——本轮只换默认图标。
