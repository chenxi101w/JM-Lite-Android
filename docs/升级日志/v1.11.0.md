# v1.11.0 — 书架批量删除：长按进多选，按已读/未读一键全选

> 用户：「长按改成批量删除吧，能直接全选 未读或者已读的」

## 交互

- **长按卡片** → 进入多选模式（首本默认选中，卡片主色描边高亮）
- 多选中点卡片 = 切换选中（不再触发导航）；卡片上的删除小按钮隐藏
- 顶部工具栏：`已选 N 本` + **全选 / 未读 / 已读** 一键勾选 + ✕ 退出
- 「删除所选（N 本）」红色按钮 → 确认弹窗 → 逐本彻底删除（与单本删除同语义：本地文件 + 书架记录 + 阅读进度，不可恢复），完成后 toast「已删除 X/Y 本」
- 单本删除路径保留：非多选时点卡片上的删除按钮，仍走原确认弹窗

## 「已读」判定

`read_progress` 表有记录 = 打开过阅读器 = 已读；没有 = 未读（下载了但没看过）。进多选模式时一次性加载（`BookLibrary.getReadBookIds()`，走 `ReadProgressDao.getAllBookIds()`）。
