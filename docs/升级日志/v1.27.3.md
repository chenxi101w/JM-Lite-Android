# v1.27.3 设置页图标：抠掉白角 + 去掉那层浅灰框

## 需求（用户原话）

> 设置页展示的那个图标能不能把粉框及其以内的全抠出来，然后别给框了，直接放这里（我看到了一个浅浅的灰框）

## 处理了什么

设置页顶部那个图标（`SettingsScreen.AppHeader`）原来是：

```
Card(圆角26dp, surfaceVariant 45% 灰)      ← 「浅浅的灰框」
  └ Image(ic_launcher_preview.png, 76dp)   ← 图本身四角带白边
```

两个问题叠在一起：

1. **图本身**是「粉色圆角方框浮在 192×192 白底上」，四个圆角外是白边 —— 看着像贴了张白纸。
2. **外面还包了一层浅灰 Card**（`surfaceVariant.copy(alpha = 0.45f)`），和图标自带的粉框叠成「两层框」。

### 改动

**1. 抠掉白角（新资源）**

- 用 `flood fill` 从四条边向内扩散，凡是与边缘连通的近白像素（lum ≥ 240）全部置为透明；
- 结果存成新资源 **`ic_launcher_preview_cutout.png`**（192×192，仅 3.2% 像素被抠掉 —— 说明粉框在四边中线处本就紧贴图像边缘，只有圆角外是白的）。

**2. 去掉灰色 Card**

`AppHeader` 里的 `Card` 整块删除，图标直接落在页面背景上，尺寸 60dp → **76dp**（原来被 Card 的 8dp 内边距和白边各吃了一圈，现在能占满同样footprint）。

**3. 其余 5 个图标变体（alt1/alt2/豆包2~4）本次不动** —— 只在默认图标上做，避免超出需求范围。

## 一个技术要点（为什么不能直接"裁掉粉框"）

粉框是**圆角矩形**，不是矩形。用矩形裁切只能削掉四边中段那一溜（约 9~10px），
**四个圆角处的粉色会留在图里**，看起来还是一圈框。

要连粉框一起去掉只能用**遮罩**。几何实测（192px 图）：

| 量 | 值 |
|---|---|
| 粉框厚度（四边中线） | 9~10px |
| 外框圆角半径 | ≈39px |
| 内边界（对角线方向） | ≈18px |
| 对角线上内边界公式 | `(R-t)(1-1/√2) + t/√2` = 29×0.2929 + 10×0.7071 ≈ 18.5 ✓ 与实测吻合 |

按此，若要走「连粉框一起去掉」的方案，遮罩应取**内缩 14px / 圆角 25px**（对角线边界 17.2 < 18，粉框全清）。

## ⚠️ 待用户确认的一点

「别给框了」可能有两种理解，两种都渲了对比图：

| 方案 | 做法 | 结果 |
|---|---|---|
| **B（本次采用）** | 抠掉白角，**保留粉框** | 干净的圆角方形图标，无白边 |
| **A** | 连**粉框**一起去掉，只留画面 | 只剩中间那张彩色插画，无任何边框 |

采用 B 的理由：用户说的是「**把粉框及其以内的全抠出来**」——「抠出来」在中文里是**把主体从背景里提取出来**（如"把这个人抠出来"），粉框是被提取对象的一部分；后面「别给框了」由括号注明指的是**浅灰那个框**。
若用户实际想要 A，只需把 `AppHeader` 里的 `ic_launcher_preview_cutout` 换成遮罩版即可（脚本 `test/ref_video/icon_options.py` 可生成）。

## 真机待验证
