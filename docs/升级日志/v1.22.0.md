**版本号**：versionName 1.22.0 / versionCode 86
**日期**：2026-10-15
**DB**：无 schema 变更
**性质**：交互/动效（MINOR）

> 用户：「你看看咱们的页面切换怎么样」。
> 对照对象仍是 **`1976764/jm-comic-android`** 的 `ui/navigation/AppNavigation.kt`。

## 一、人家的做法（原文照抄）

```kotlin
NavHost(
    navController = navController,
    startDestination = Routes.MAIN,
    // 前进：新页面从右侧滑入，当前页微向左移
    enterTransition = { slideInHorizontally(tween(250)) { fullWidth -> fullWidth } },
    exitTransition  = { slideOutHorizontally(tween(250)) { fullWidth -> -fullWidth / 4 } },
    // 返回：当前页向右滑出 + 渐隐；上一页同时淡入
    popExitTransition  = { slideOutHorizontally(tween(220)) { fullWidth -> fullWidth } + fadeOut(tween(220)) },
    popEnterTransition = { fadeIn(tween(220)) },
)
```

**关键点不在 NavHost，而在底部 Tab**：他们的 Tab 不是路由，而是
`var selectedTab by rememberSaveable { mutableIntStateOf(0) }` + `when (selectedTab) { 0 -> Home… }`
—— **切换时没有任何动画，瞬时换内容**。
「人家切换非常流畅」的一半原因在这里：Tab 切换是**零延迟**的，不是「动画很短」。
（另一半是 push/pop 用了有方向感的水平滑动，而不是淡入缩放。）

## 二、我们 v1.19.0 做错在哪

| | 人家 | 我们 v1.19.0 |
|---|---|---|
| 进下级页 | 右侧整屏滑入 250ms + 当前页左移 1/4（**视差**） | 淡入 + 0.94→1 缩放 |
| 返回 | 右滑出 + 渐隐 220ms，上一页淡入 | 淡出 + 缩放 |
| **底部 Tab 互切** | **无动画，瞬时** | **也走了同一套 200ms 淡入缩放 → 每次切 Tab 都「慢半拍」** |
| 阅读器 | 与其它页同一套 | 单独设了纯淡入（特例） |

两条错：① 用淡入缩放代替水平滑动，**丢了方向感**（滑动的方向本身在告诉用户「进了下一层」）；
② 给所有路由套同一套动画，**连最该瞬时的 Tab 切换也拖了 200ms**。

## 三、本轮改法

1. **转场换成 push/pop**（时长照抄）：`enter` 右滑入 250ms；`exit` 左移 1/4 屏 250ms（视差）；
   `popExit` 右滑出 + 渐隐 220ms；`popEnter` 淡入 220ms。
2. **Tab 互切 → 无动画（瞬时）**：新增 `isTabSwitch()` 判断，两侧都归一到某个顶级 Tab 时
   返回 `EnterTransition.None` / `ExitTransition.None`。
3. **删掉阅读器的淡入特例**，与其它页统一走 push/pop。
4. 归一化**复用已有的 `topLevelRouteOf()`**（它已把 `search/{q}/{mode}` 归到 `search`），
   **没有另立一份 Tab 路由清单** —— 否则两处清单迟早漂移。

### 比人家还好一点的地方（保留我们原来的架构）

人家的 Tab 是 `when(selectedTab)` 直接换内容 —— 代价是**每次切 Tab 都重建屏幕**（丢滚动位置）。
我们是 `nav.navigate(route) { popUpTo(start){saveState=true}; restoreState=true }`，
**既有瞬时切换（None），又保留各 Tab 的滚动位置与状态**。

## 五、真机待验证

1. **切底部 Tab**：应当是「啪」一下到位、无过渡延迟。
   ⚠️ 副作用风险：无动画意味着目标页**没有淡入遮罩**，若某 Tab 首次组合较慢，
   可能出现一帧空白闪现。若真机看到闪白，就把该 Tab 的 `None` 换成 120ms 短淡入。
2. **进详情 / 返回**：右侧滑入、返回滑出，方向感应清晰；`exit` 的 1/4 视差是否自然。
3. **进阅读器**：现在是水平滑入（原为纯淡入）。若全屏看图时觉得滑动「晃眼」，
   把阅读器路由单独改回 `fadeIn` 即可（一行）。
