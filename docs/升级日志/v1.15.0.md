# v1.15.0 — 回收站（自全量版 v7.1.x 移植）

> 删除语义从「彻底删除不可恢复」升级为「进回收站可恢复」，对齐全量版 v7.1.3 宽限期模型。
> 数据层（recycleAt/trashed 列、RecycleManager、BookLibrary API、到期扫描）在轻量版中**早已就位**，
> 本版补齐的是**删除语义接线 + UI + 入口**。

## 行为变化

- 书架删除（单本/批量）：从「彻底删除不可恢复」→「删本地内容并进回收站，可在回收站恢复或彻底删除」；
  确认弹窗文案同步更新。
- **标看完（手动/自动）即进回收站宽限期**：7 天没再看自动删本地内容；重开已看完的书 = 宽限期续期 7 天。
- 回收站页（新）：书架顶部「回收站（N）」入口——两态列表（宽限中可读 / 已删需重下）、恢复、彻底删除、清空；进页即扫描超期项。
