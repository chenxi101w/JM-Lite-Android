## 版本说明

## 一、删除搜索框下方的耗时小字

v1.1.0 加过一行「上次搜索 xxx ms · JSON接口」，用于验证提速效果。现已**删除**：

- 移除 `SearchScreen` 中的展示（`vm.lastPerf` 订阅一并移除）。
- **耗时记录本身保留** —— `SearchPerfLog` 照常采样，「关于」页仍可查看统计并导出紧凑串。
  只是不再占用搜索页的视觉空间。

## 二、点搜索后自动收起输入法

在搜索（回车 / IME 搜索键）后立即收键盘，让结果区域占满视野。

**踩坑记录**：只调 `focusManager.clearFocus()` **不生效** ——
实测键盘仍停留在屏幕上（截图确认），因为 TextField 清焦点后 IME 未必跟随隐藏。

```kotlin
// 正确做法：两者配合
focusManager.clearFocus()
keyboardController?.hide()      // LocalSoftwareKeyboardController
```

**验证**：回车后 `dumpsys input_method` → `mInputShown=false` ✅

## 三、搜索栏上移

搜索框原本离顶部偏空。调用处（`DiscoverScreen`）的 `PaddingValues(vertical = 12.dp)`
改为只保留底部、顶部收窄：

```kotlin
PaddingValues(start = 12.dp, end = 12.dp, top = 2.dp, bottom = 12.dp)
```

**验证**：搜索框 bounds 由 `[36,156][1044,348]` → **`[36,126][1044,318]`，上移 30px（约 11dp）** ✅
底部仍保留 12dp，避免结果列表贴住底部导航。

## 五、调试方法留存

本次全部用 adb 完成自动化验证，无需人工点击：

```bash
# 1) 取控件精确坐标（Compose 界面同样能拿到 text/bounds）
adb shell uiautomator dump /sdcard/u.xml && adb shell cat /sdcard/u.xml

# 2) 切 tab / 点输入框 / 输入 / 回车
adb shell input tap <x> <y>
adb shell input text "art"          # 中文不支持，改用英文或数字
adb shell input keyevent 66         # ENTER

# 3) 截图核对（截图坐标需按 `adb shell wm size` 换算：物理 1080×2400）
adb exec-out screencap -p > shot.png

# 4) 键盘状态
adb shell dumpsys input_method | grep mInputShown
```

**注意**：底部导航项的点击坐标要从 dump 里取（本例 y=2346），凭感觉点容易落到内容区（会误入阅读器）。
