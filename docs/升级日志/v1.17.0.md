## 三、DB 迁移（14 → 15）

删表 9 张：`subscriptions` / `sub_updates` / `tag_library` / `tag_library_exp` / `blacklists` / `blocks` / `categories` / `comic_categories` / `aliases`。
删列 3 个：`comics.blocked` / `comics.recycleAt` / `comics.trashed`。

⚠️ **不能用 `ALTER TABLE DROP COLUMN`**：它要 SQLite 3.35（Android 12+），本App minSdk=24，Android 11 及以下自带 SQLite 3.28 会直接报错。因此走官方 12 步改表法：建 `comics_v15` → 拷 16 列 → 删旧表 → 改名 → 重建 `index_comics_localDir`。

**新表 DDL 逐字照抄 Room 导出的 schema JSON**（临时开 `exportSchema` + ksp schemaLocation 导出 v14 真值，用完即撤）—— 手写必错，列类型/DEFAULT/PRIMARY KEY 任一处对不上，Room 启动校验就抛 `IllegalStateException`，App 崩在启动页。
