## 二、转场按层级区分（解决「切哪个都是左翻页」）

**根因**：v1.22.0 把 NavHost 的**默认**转场设成了横滑（那是「层级下钻」该用的动画），
于是**平级跳转**也被横滑了 —— 详情 → 搜索结果、任意进详情，全都往左翻。

按 M3 的选型（**横滑只用于层级下钻，平级用 fade through**）重新分配：

| 场景 | 之前 | 现在 |
|---|---|---|
| Tab ↔ Tab | 瞬时 | 瞬时（不变） |
| **列表 → 详情（层级下钻）** | 横滑 250ms | **横滑 250ms + 1/4 屏视差（不变，唯一该横滑的）** |
| **详情 → 搜索结果 / 设置二级页（平级）** | 横滑 250ms | **淡入淡出 190/170ms** |
| **阅读器（全屏看图）** | 横滑 | **纯淡入 160ms**（横滑会让画面晃眼） |

实现方式：NavHost 级默认改成淡入淡出 + `isTabSwitch()` 判瞬时；
`composable(Routes.DETAIL)` 与 `composable(Routes.READER)` 各自**覆盖**四件套转场。

## 三、主页「双隐藏栏」：现状与需要你拍板的地方

- **底部导航栏随滚动隐藏**：可以做，方案见知识库 `01-滚动隐藏栏/02`。
  我们已有现成的 `NestedScrollConnection`（v1.23.0 为悬浮球接的那一层），复用即可。
- **顶部搜索栏**：**我们主页现在没有**（`LibraryScreen` 是 `showTopBar = false`，没有搜索框）。
  做一个「随滚动隐藏的搜索栏」属于**新增功能**（新 UI + 搜索入口），
  按规矩不擅自加 —— 你点头我就做。

> 补充一条事实：参考实现**也没有**滚动收拉（全仓库 `scrollBehavior` = 0），
> 它主页那两个「隐藏栏」应该是原生控件自带的行为，不是它自己写的动画。
