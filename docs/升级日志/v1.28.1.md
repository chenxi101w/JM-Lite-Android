## 一、🔴 修 v1.28.0 的排序枚举错误

v1.28.0 我按推测写了 `md`(总排名) / `mv_m`(月排名) / `mv_w`(周排名) —— **全是无效值**。
从参考实现解包产物（`AI-Android/Knowledge Base/解包`）的 `CategoryGroups.kt` 注释里拿到权威映射：

| 界面 | order | time |
|---|---|---|
| 最新 | `mr` | `a` |
| 最多喜欢 | **`tf`** | `a` |
| 总排名 | **`mv`** | `a` |
| 月排名 | **`mv`** | **`m`** |
| 周排名 | **`mv`** | **`w`** |

**关键认知：月/周排名不是独立的 order 值，是 `order=mv` + `time=m/w`。**

改动：
- 排序项从 `Pair(order, label)` 改成 `SortOpt(order, time, label)`；
- `JmApiClient.search()` 新增 `time` 参数；
- `BookLibrary` 白名单：`order ∈ {mr, tf, mv, mp, tr}`、`time ∈ {a, w, m}`；
- 回落兜底照旧（拿不到结果 → 用 `mr/a` 重试）。

## 二、漫画展示重构

### 2.1 网格：默认 3 列 → **2 列**，外边距 4dp → 20dp

| | 改前 | 改后 |
|---|---|---|
| 列数 | `Fixed(3)`（"自适应"那档也被钉成 3） | **`Fixed(2)`** |
| 外边距 | `PaddingValues(4.dp, 4.dp)` | **`PaddingValues(20.dp, 8.dp)`**（照参考） |
| 项间距 | 12 / 16 | 不变 |

封面更大、左右留白更足，从「网页列表」变成「精选流」观感。

### 2.2 卡片：减重 + 两种风格

原来那张卡（现约 640 行）把它叫「重」不是贬义 —— 它同时挂着：
`Card` 容器（描边+阴影+选中态）、封面半透明蒙层、**两条胶囊角标**（已下载/已看完）、
**一整条操作条「左下载 + 右收藏」**。3 列一屏 9 张时非常吵。

现在：

- **去掉 `Card` 容器** —— 不再有描边/阴影/容器色，封面 + 文字直接铺在页面底上（照参考）；
- **两条胶囊角标 → 右下角一个小圆点（6dp）**，状态还在，噪声没了；
- **操作条移除**，收藏/下载改到封面角上（见 2.3）；
- 标题 `minLines = 2`：保证同行卡片等高，网格不参差；
- 新增 `cardStyle` 参数，两种风格可切：

| 值 | 名称 | 做法 |
|---|---|---|
| `clean`（默认） | **干净优先** | 封面 + 两行标题 + 一行作者；封面圆角 12dp |
| `immersive` | **大图流** | 封面圆角 16dp + **底部渐变遮罩**（黑 78%→透明），标题**压在封面底部**，封面下只留一行作者 |

### 2.3 封面角上的透明方形小按钮（用户明确要求）

> 「收藏和下载放漫画左上右上，**透明正方形**同时**小一点**」

- **收藏 → 左上**，**下载 → 右上**；
- **不画任何底色/描边**（透明的方形触摸区，圆角 6dp），只有图标本身；
- **小一点**：触摸区 `28dp`、图标 `17dp` —— 原来是 40dp 触摸区 + 圆形填充的 tonal `IconButton`；
- 状态色：未激活 = 白（`Color.White` 92%，压在封面上可读），激活 = 主题色（已收藏/已下载一眼可辨）；
- 已下载时点它 = 删除下载；多选态下自动让位给左上角的勾选圆钮（避免同角叠两层）。

### 2.4 新增设置项

设置 → 搜索：

| 项 | 选项 | 默认 |
|---|---|---|
| **网格密度**（原「结果列数」改名） | 2 列 / 3 列 / 4 列 | **2 列** |
| **卡片样式** | 干净优先 / 大图流 | 干净优先 |

## 三、⚠️ 本次没做的：分类放首页

用户要求「分类放首页，搜索下面」。**没做，原因是要先验接口**：

- 参考的分类**不是关键词搜索**，是走 **`categories_filter` 接口**（`category` + `orderBy` + `time`）；
- 我们的 `JmApiClient` **只有 `search`**，没有这个接口；
- 移动端 API 唯一认的 category 值只有：`doujin / single / short / hanman / meiman / another / 3D`，
  **其它 slug 会被服务器静默回退成「全部」**（参考源码注释里的实测结论）；
- 该接口**在本项目的签名/线路链路下能否跑通未验证过**。

所以分类是**下一步的第一件事**：先写最小验证（拉一页 `doujin`），通了再做页面。
