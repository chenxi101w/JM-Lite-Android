## 零、本轮已修：图片之间留白过多（用户反馈）

### 根因（两个叠加）

`ReaderScreen.kt` 原实现：

```kotlin
LazyColumn(verticalArrangement = Arrangement.spacedBy(4.dp)) {
    AsyncImage(
        contentScale = ContentScale.Fit,                     // 不裁剪：比例不符的部分全成白
        modifier = Modifier
            .fillMaxWidth()
            .height(screenHeightDp.dp * 0.95f)               // 强制固定高度 = 屏高的 95%
            .padding(2.dp))
}
```

| # | 问题 | 后果 |
|---|---|---|
| 1 | **固定高度（屏高×0.95）+ `ContentScale.Fit`** | 图片按比例缩放后，框内空出的部分全是留白。以常见页 702×1000 为例：按宽度铺满后高约 513dp，而框高约 760dp → **每页白白空出约 30% 屏高** |
| 2 | 右滑轨预留 `padding(end = 8.dp)` | 图片右侧固定 8dp 白边 |
| 3 | `spacedBy(4.dp)` + 每页 `padding(2.dp)` | 页与页之间额外 8dp 空隙 |

### 修复

```kotlin
LazyColumn(verticalArrangement = Arrangement.spacedBy(0.dp)) {   // 逐页首尾相接
    val painter = rememberAsyncImagePainter(model = File(p))
    val ratio = 真实宽高比 ?: DEFAULT_PAGE_RATIO                  // 0.72 兜底
    Image(
        painter = painter,
        contentScale = ContentScale.FillWidth,                    // 按宽度铺满，高度随比例自适应
        modifier = Modifier.fillMaxWidth().aspectRatio(ratio))
}
```

- 去掉固定高度与 `Fit`、去掉每页 padding、页间距归零、去掉右侧 8dp 沟槽（滑轨改浮层）。
- 占位框也用 0.72 比例，避免「高度 0 → 突然撑开」的滚动跳动。
- 效果：**每页按自身比例严丝合缝铺满宽度，零留白**。

## 一、下一步：阅读链路才是大头

留白是观感问题，**「能不能看 / 看得快不快」** 是功能问题。当前阅读器的两条硬伤：

| 现状 | 后果 |
|---|---|
| `loadLocalPaths()` 只读本地已下载目录，找不到就报「本章未下载，请到详情页下载后阅读」 | **未下载的章节完全读不了**（v5.0.18 起移除了在线阅读） |
| 本地图片由 Python 下载时「解码 + scramble 还原 + 重编码」产出 | 下载慢（详见 `下载优化_20260929.md`：75% 的 CPU 是绕道浪费） |

### 关键前置：scramble 还原（Kotlin 实现）

这是**恢复在线阅读**与**下载提速**的共同钥匙：

- 规则：`aid < scramble_id` 或 GIF → 不需要还原；否则图片被竖向切成 `num` 块**倒序重排**；
- `num = get_num(btoa(aid), btoa(page))`；
- 算法原型：同源客户端 `utils/Function.js: scramble_image`（切块 + 倒序 + `drawImage`）；
- Android 侧用 `Bitmap` + `Canvas.drawBitmap` 等价实现。

### 做完之后能解锁

| 能力 | 说明 |
|---|---|
| **在线阅读** | `comic_read` 接口拿图片直链（实测可用、无需 Referer）→ Coil 加载 + 还原 → **不必先下载就能看** |
| **下载提速** | 下载只存原始 webp（零解码），或原生一次还原，省 75% CPU |
| **存储减半** | 存 webp 原图（120KB）而非还原后 JPEG（250~400KB） |
| **去掉 Python** | 阅读+下载全 Kotlin 后，Python 只剩残留价值 |

## 二、其余可优化项

| # | 项 | 说明 | 收益 |
|---|---|---|---|
| 1 | **Coil 解码降采样** | 阅读大图按屏宽降采样（`size(...)`），避免整张原图进内存 | 防 OOM、滚动更跟手 |
| 2 | **预加载相邻页** | 滚动时预取下一页（已有本地文件时仅预解码） | 消除翻页白屏 |
| 3 | **翻页模式** | 现有仅连续滚动；可加左右翻页（单页）、双页 | 阅读习惯 |
| 4 | **亮度/背景调节** | 全屏亮度调节、纯黑背景（OLED 省电） | 夜间阅读体验 |
| 5 | **双指缩放** | 现有是否支持需确认 | 看细节 |
| 6 | **滚动惯性/边界回弹** | 长条漫画的连续滚动手感 | 手感 |
| 7 | **章节切换手势** | 读到末尾滑动直接进下一章 | 连贯性 |

## 三、建议推进顺序

1. ✅ **修留白**（本轮，已做）
2. **实现 scramble 还原 + 恢复在线阅读** ← 收益最大，一步解锁「在线可读 + 下载提速 + 存储减半」
3. 预加载相邻页 + Coil 降采样（防 OOM、消白屏）
4. 翻页模式、亮度调节等体验项

## 四、验证要点（本轮留白修复）

1. 打开任一章 → 页与页之间应**首尾相接、无大片空白**。
2. 滚动到底再回滚 → 不应有「高度跳变」。
3. 进度滑轨仍可拖动定位，且不遮挡内容（浮层）。
4. 用一本**宽高比特殊**的漫画验证（如条漫、宽幅页）→ 不应出现拉白。
